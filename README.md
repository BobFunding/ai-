# Mobile Webapp Flow

서비스 분야에 맞게 모바일 웹앱의 첫 체험, 입력·실행, 피드백, 결과 확정, 다음 행동을 설계하고 구현하는 Codex 스킬입니다.

## 사용

이 저장소를 로컬의 `~/.codex/skills/mobile-webapp-flow` 폴더에 복사한 뒤 다음처럼 호출하세요.

```
$mobile-webapp-flow를 사용해 예약 서비스 모바일 웹앱을 설계하고 구현해줘.
```

서비스마다 필요한 단계를 선택하며 특정 화면 수, 브랜드, 색상, AI 기능을 강제하지 않습니다. 모바일 키보드와 하단 버튼, 입력 보존, 비동기 오류 처리, 실제 완료 확인을 포함합니다.

## 구성

- `SKILL.md`: 설계·구현·검증 지침
- `agents/openai.yaml`: 스킬 표시 정보
- `references/domain-adaptation.md`: 분야별 적용 예시
- `references/observed-pattern.md`: 참고한 상호작용과 관찰 한계

참고 앱의 이미지·코드·브랜드 자산은 포함하지 않습니다. 개인 경로, 계정 정보, 기기 식별자, 대화 원문은 포함하지 않습니다.
